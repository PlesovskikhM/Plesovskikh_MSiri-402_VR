1.Отличие коллайдера от коллизии
Коллайдер — это компонент, который прикрепляется к игровому объекту, чтобы определить его границы для расчетов физики.
Коллизия —  Это сам процесс физического контакта, который регистрируется программой, когда два коллайдера пересекаются или соприкасаются.
2. Отличие while от do while
while - сначала проверяет условие, а затем выполняет код внутри. Если условие изначально ложно, код в цикле не выполнится ни разу.
do while - сначала один раз выполняет код внутри цикла, и только потом проверяет условие. Этот цикл гарантированно выполнится хотя бы один раз, даже если условие сразу окажется ложным.
3. Методы Web-запросов (HTTP-методы)
GET — запрашивает данные с сервера (например, загрузка страницы или получение профиля игрока).
POST — отправляет новые данные на сервер для создания чего-то нового (например, регистрация или отправка счета в таблицу лидеров).
PUT — полностью перезаписывает существующие данные на сервере.
PATCH — частично обновляет данные (например, меняет только имя пользователя, не трогая остальной профиль).
DELETE — удаляет данные или ресурс с сервера.
4. Когда используется OnCollision и OnTrigger
OnCollision используется, когда объекты физически сталкиваются и отскакивают друг от друга. Для этого у объектов должны быть твердые коллайдеры и хотя бы один компонент Rigidbody.
OnTrigger используется для зон обнаружения, когда объекты должны проходить друг сквозь друга без физического столкновения.
5. Для чего нужен интерфейс / класс Input
С его помощью программа понимает, что пользователь нажал клавишу на клавиатуре, кликнул мышкой, отклонил стик на геймпаде или коснулся экрана смартфона, и позволяет связать эти действия с логикой игры.
